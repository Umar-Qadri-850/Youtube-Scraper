# YouTube Latest Video & Transcript Scraper

A YouTube scraper that accepts a **YouTube channel URL**, automatically finds the **latest uploaded video**, extracts its metadata and transcript, and returns everything in a clean, structured **JSON response**.

## Features

- Accepts a YouTube channel URL
- Automatically finds the latest uploaded video
- Extracts video metadata
- Retrieves available transcripts
- Supports auto-generated transcripts
- Detects transcript language
- Returns available transcript languages
- Includes transcript timestamps
- Returns structured JSON
- Suitable for AI, translation, summarization, and content-monitoring workflows
